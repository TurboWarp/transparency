# TurboWarp DMCA transparency

For transparency, this repository contains DMCA notices that we've received for content on turbowarp.org, turbowarp.xyz, or forkphorus.github.io. You can find them in the [notices] folder.

Disputes regarding content created with the [TurboWarp Packager] or [forkphorus packager] are not in scope for this repository as the TurboWarp project is not a party to those disputes.

Due to the nature of DMCA law, we are not able to discuss the notices or their legitimacy beyond the details shared here.

[notices]: ./notices
[TurboWarp Packager]: https://packager.turbowarp.org/
[forkphorus packager]: https://forkphorus.github.io/packager/
